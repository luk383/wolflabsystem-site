ANDROID APP · ALPHA 0.5.1

WOLFLAB for Android.

An alpha Android app: a strength workout builder, endurance calculations on your own profile (Engine) and two offline guides. Your data stays on the phone. It is a test version, not a finished product: below you can see what it does, how to install it and what has not been verified.

Download APK 0.5.1 alpha · 3.3 MB

Alpha, not published on Google Play. Android will show a warning because the app comes from outside the store.

What it does

  • Workout Builder: pick equipment, time (30, 45 or 60 minutes), goal and experience; the app proposes a workout, including isometrics (sets × duration), and you can swap exercises one by one, save it, edit it, duplicate it, rename it or delete it. For each exercise you can set sets, reps, load and notes. Library of 53 exercises.
  • Wolf Engine: enter age, weight and the data you have (race times over 5 km, 10 km, half and marathon, FTP, heart rate, 200 m and 400 m swim tests, sweat rate). The app computes paces and zones for running and cycling, an estimated swim CSS (Daniels, Friel and Coggan methods for paces, heart-rate zones and power), a carbohydrate and fluid estimate and splits for 10K, half and marathon. Only what your data allows is shown. These are method estimates, not prescriptions.
  • Offline guides: Swimming (how to read a session, intervals, pool and open water) and Weight training. Introductory, readable without a connection.
  • Profile and backup: save your profile on the phone, download a backup of workouts and profile as a JSON file and restore it from a file, including backups from the 0.x versions.

Data and privacy

No account, no sign-up. Profile and workouts are stored on the phone; the backup is a file you download yourself. The app does not send data to WOLFLAB servers: the internal page declares a security rule that blocks network connections (connect-src none) and we found no network requests in the code. This is not an absolute guarantee about traffic. The Android manifest lists a single permission, INTERNET. No account required, no ads or telemetry declared. Links to the website open only if you tap them.

How to install

  1. On an Android phone (7 or later) tap the «Download APK» button. The browser may warn that the file is an APK: confirm the download.
  2. Open the downloaded file. If Android asks, allow the browser or file manager to install unknown apps, for this installation only.
  3. Tap Install, then Open. After installing you can remove that permission again.
  4. Optional: check the SHA-256 checksum before installing (see below).

How to update

There is no automatic update: the app is outside Google Play, so updates are manual. This APK has the same signature and package as versions 0.3.1 and 0.4.1 (certificate below) and a higher versionCode: Android should install it over the previous version without uninstalling. If you already have workouts, first download a backup from Profile > Scarica backup (in 0.3.1: workout > Dati, salvataggio e backup > Esporta JSON di prova).

If Android reports a signature conflict (for example with a test build), do not uninstall: stop and write to us from the Contact page. Uninstalling the app deletes the data saved on the phone.

What has been tested

On a POCO F6 phone, by the project owner: the app opens, the header does not overlap the Android status bar, and a 5-exercise workout that was generated and saved is still in Home after fully closing and reopening the app. The checksum and certificate below were checked on the published file.

Limits

  • Alpha version: errors are possible. No general guarantee that it works.
  • Not tested on the phone: Engine and guides, backup and restore, importing real data from earlier versions (checked only with test data), the Android Back button on every screen, the launcher icon, other phones and Android versions.
  • Updating over a previous version has not been tested on a phone.
  • The app is in Italian only.
  • Do not keep the only copy of data you need inside the app: download a backup and check you can reopen it.
  • Engine estimates and guides are informational: they are not a prescription or medical advice.
