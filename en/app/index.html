ANDROID APP · ALPHA 0.5.1

WOLFLAB for Android.

An alpha Android app: build strength workouts, calculate paces and zones for running, cycling and swimming, with two offline guides. No account, data stays on your phone.

Download APK 0.5.1 alpha · 3.3 MB

Alpha, not published on Google Play. Android will show a warning because the app comes from outside the store.

What it does

  • Workout Builder: pick equipment, time and goal, and the app proposes a strength workout. You can swap exercises, save it and edit it.
  • Wolf Engine: enter your data (race times, FTP, swim tests) and get paces, zones, carbs and race splits. These are estimates, not prescriptions.
  • Offline guides for swimming and weight training, and a backup to a file you download yourself.

How to install

  1. On an Android phone (7 or later) tap «Download APK» and confirm the download.
  2. Open the file. If Android asks, allow the browser or file manager to install unknown apps.
  3. Tap Install, then Open.

To update from an earlier version, install this file over it without uninstalling, and if you have workouts, export a backup first. If Android reports a conflict, do not uninstall: write to us from Contact, because uninstalling deletes the data.

Alpha version, Italian only, not on Google Play: errors are possible, updates are manual. Tested so far on a single phone.
