WOLFLAB for Android.

Alpha 0.2.0: basic calculators and offline swimming and weights guides, data stays on your phone. A test, not a finished product.

Download APK · 3.3 MB

Alpha, not published on Google Play. Android will show a warning because the app comes from outside the store.

Status

  • Alpha version: limited features, errors possible.
  • TRAIN is in preparation: three proposed paths, no working programmes and no prescribed sessions.
  • This signed APK has not yet been tested on a phone.
  • Not on Google Play. Updates are manual.

What is in it

  • PACE, FTP, FUEL, RACE and ZONES: five basic calculators, with method and limits stated in the app.
  • Offline swimming and weights guides, with pace per 100 m and splits (arithmetic only, not CSS or zones) and an external-load calculation (arithmetic, not a prescription). Favourites are saved on the phone.
  • No weekly programmes or plans, and no set and rep log.
  • MyWolf: preferences saved on the phone only if you choose to save them, and deletable.
  • No account, no telemetry, no GPS, no Garmin or Strava link, no AI chat.

Data and privacy

The app does not send data to WOLFLAB servers. Inside the package, the web page carries a security rule that blocks network connections (connect-src none). Android lists the INTERNET permission in the manifest: it is in the package, but the app code makes no network requests. External links open only when you tap them, in the browser.

How to install

  1. Download the file with the button above.
  2. Open the file. If Android asks, allow your browser or file manager to install unknown apps, only for this install.
  3. If you want, check the SHA-256 checksum below first.
  4. If you have 0.1.0: same app, same signature, higher version (versionCode 2). An in-place update is expected but has not been verified on a phone; if you want to keep your data, note it first. There is no automatic update.

If you installed the test (debug) build, it has a different signature: this APK will not update it. Note the data you want to keep and uninstall that build first: local saves are lost.
